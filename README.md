# ToDoList
A python program to create your own to do list 

##features 

- Add tasks with an expected date to complete within
- View all your pending and completed tasks in one place
- Mark tasks as done and automatically check if you finished on time or late
- Delete tasks you dont need anymore
- Colored terminal output so its easier to read

 ## How to use
- Download todo.exe from the Releases page.
- Pick an option from the menu (1 to 5).

##Note:
When adding a task, enter the expected finish time in this format of YYYY-MM-DD HH:MM (for example: 2026-11-24 18:30 ).
